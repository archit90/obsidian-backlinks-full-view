# Backlinks Full View: test catalogue

Deep test of the plugin in a real Obsidian 1.15.0 (sandbox copy of test vault 948, 20,023 notes), driven over
the DevTools protocol with real mouse and key input (`e2e/run.mjs`, cases in `e2e/cases.mjs`, fixtures in
`e2e/fixtures.mjs`, last results in `e2e/results.md`). Every automated case below has the same id there.
`<select>` dropdowns and clicks inside a popout window are driven by events (CDP input can't reach them); every
other click, hover and keystroke is real input.

**Final full run: 2026-11-08, after `backlinks-open`: 92/92 automated cases, 279/279 checks PASS** (`e2e/results.md`; that run
named B10–B12 B9–B11, renumbered after it), plus
V1–V3 by eye and the TYPING / BUILD gates. Status `fixed` = failed in the first run, root-caused and fixed in this
round (see the report), passing now.

Fixtures (`_bfv/`, rewritten before each group that needs a clean slate): `Target` (aliases `TA`, a self-link,
one own pane "Mine" sorted by `rank`) and ten notes that link to it in every way: plain, `#heading`, `#^block`,
embed, `|display`, alias name `[[TA]]`, Markdown links, a frontmatter-only link, one beside an unresolved link,
and two notes with broken `backlinks`. Plus `Orphan`, `Lonely`, `Short`, property variants (`Bad list`, `Bad json`,
`Bad entry`, `Single obj`, `Yaml filter`, `Empty list`, `Null entry`, `Titles`, `Mismatch`, `Open list`),
`Queries`, `DVJS`, `Canvas.canvas`. Hub: `n/Maya Iyer` (3,001 backlinks).

Sources: S = SPEC.md §4 (§3 common ground, §10 status), Y = system.md (Backlinks Full View, properties), CS =
common sense (spec silent).
