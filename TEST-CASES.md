# Backlinks Full View: test catalogue

The plugin's cases, each run in a real Obsidian 1.15.0 in a throwaway sandbox (`e2e/sandbox.sh`: its own virtual
display, profile and vault), driven over the DevTools protocol with real mouse and key input (`e2e/run.mjs`, cases in
`e2e/cases.mjs`, fixtures in `e2e/fixtures.mjs` and `e2e/make-vault.mjs`, last results in `e2e/results.md` and
`e2e/results-together.md`). Every automated case below has the same id there. `<select>` dropdowns and clicks inside a
popout window are driven by events (CDP input can't reach them); every other click, hover and keystroke is real input.

**Alone**, in a fresh empty vault with only this plugin (a case that needs another plugin prints SKIP):

```sh
npm run build && e2e/sandbox.sh reset 1 && npm run e2e
```

**Together** with Dataview and Editor Multiple Lanes (another sandbox state; stop the first sandbox before):

```sh
e2e/sandbox.sh stop 1
OBS_PLUGINS=blacksmithgu/obsidian-dataview@0.5.68:<folder of an Editor Multiple Lanes build> \
  OBS_SANDBOX_DIR=$PWD/.sandbox-together e2e/sandbox.sh reset 1 && npm run e2e:together
```

`npm run e2e:together` sets `E2E_REQUIRE=dataview,editor-multiple-lanes` (a skipped case that needs them fails) and
writes `e2e/results-together.md`. For scale, `OBS_VAULT=<a big vault>` copies that vault instead of a fresh one (the
suite writes only `_bfv/` there, and the hub if it has none).

**Last runs (2026-11-08):** alone: 329/329 checks, 101/101 cases passed, 8 skipped (also after the switch to the
plugin's own debounce). Together: 352/352 checks, 109/109 cases passed, 0 skipped; after the debounce switch
351/352: **C2-reading "ctrl+alt: split" is intermittent together with Lanes** (failed 2 of 5 runs, passes alone;
open: the check may find a Lanes card leaf of the same note).

**Needs:** a case that tests working with another plugin names it (`dataview`, `editor-multiple-lanes`, or
`core:<id>` for a core plugin) and is skipped without it. The contract cases (I3–I5, K4, K5, L2, L3, C7, Q9) simulate
the other plugin's side, so they run alone too (see `SPEC.md`, Working with other plugins).

Fixtures (`_bfv/`, rewritten before each group that needs a clean slate): `Target` (aliases `TA`, a self-link,
one own pane "Mine" sorted by `rank`) and ten notes that link to it in every way: plain, `#heading`, `#^block`,
embed, `|display`, alias name `[[TA]]`, Markdown links, a frontmatter-only link, one beside an unresolved link,
and two notes with broken `backlinks`; Block also holds this plugin's own keys (`backlinks-open`,
`canvas-full-backlinks-enabled`). Plus `Orphan`, `Lonely`, `Short`, property variants (`Bad list`, `Bad json`,
`Bad entry`, `Single obj`, `Yaml filter`, `Empty list`, `Null entry`, `Titles`, `Mismatch`, `Open list`), `Bad yaml`
(frontmatter that isn't valid YAML), `Queries`, `DVJS`, `Canvas.canvas`; `_bfv/emb/` for embeds. Hub: `n/Maya Iyer`
with a "Logs" pane filtered to `0/`, and 3,000 notes in `0/` that link to it (3,001 backlinks with Alias), written on
disk by `e2e/make-vault.mjs`, which also sets the vault settings and core plugins the cases rely on.
